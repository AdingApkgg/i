# Vidstack 播放器迁移

目标：全站自有音频、视频播放统一使用 Vidstack。用户确认保留悬浮音乐外观，文章视频采用标准视频界面。

架构：全局音乐播放器保持在 SiteShell，使用 MediaPlayer / MediaProvider 管理播放生命周期，Zustand 继续管理歌单和面板。音乐按钮、进度和音量使用 Vidstack 控件。文章视频继续兼容旧 DPlayer 标签，使用默认视频布局和捆绑的 hls.js，点击前不加载媒体。

边界：第三方 iframe 保留平台播放器；纯 HTML 导出继续自包含。此改动不涉及数据库迁移，不自动发布生产。备份导出 PR #36 独立保留。

验证与约束：安装、构建、类型检查、测试和浏览器全部在 localhost-1；不覆盖已有开发目录。使用独立目录及现有开发数据库，真实解码短音视频夹具，避免依赖 Meting 或外网媒体可用性。
