# Video.js 10 与音乐歌单、滚动歌词

用户要求：全站迁移到 Video.js 10，保留当前悬浮音乐播放器外观，补上歌单和滚动歌词。

保留桌面左下角唱片与展开卡片、樱粉配色、封面动画和音频可视化；播放器仍挂载在 SiteShell，路由变化不中断。现有手机隐藏悬浮音乐的规则沿用，文章视频继续适配手机。文章内选播与默认 Meting 歌单共用当前播放队列，队列面板展示歌名、歌手、当前项，点击切歌并定位当前歌曲。该歌单指当前播放列表，不新增后台歌单数据库或收藏系统。

采用 @videojs/react 10.x 的 AudioPlayer / Audio、标准视频皮肤与 HLS 适配器，删除 Vidstack 依赖、样式、兼容补丁及 Docker 的补丁复制。保留旧 DPlayer 富文本节点名，兼容既有 JSON 和旧正文；第三方 iframe 使用平台自己的播放器。视频保留点击才加载、封面、中文控制、错误重试和原始媒体链接。

实现者默认决定：展开卡片增加“歌词”开关，与歌单面板可独立切换。LRC 随当前时间高亮并滚动，点击有时间戳的歌词定位播放位置；允许手动浏览后暂停跟随，并提供回到当前行。支持多时间标签、毫秒精度和 offset；相同时间的原文与翻译合并显示。纯文本歌词可阅读，不伪造同步时间。缺失、空歌词、请求失败都有清晰状态；失败可重试，不能影响音频播放。歌曲改变立即清除上一首歌词，异步旧响应不覆盖新歌。

歌词由 MetingSong.lrc 获取，可为 LRC 地址或内联文本。仅打开歌词时请求；浏览器查询缓存按当前歌词来源隔离。进度和歌词的高频更新留在播放器订阅中，不写 Zustand 持久化；只保留现有音量和静音偏好。歌词作为文本渲染，拒绝非 HTTP(S) 远程地址。

不新增数据库迁移，不修复历史缺失视频素材，不自动部署到生产。代码提交 PR，CI 与 localhost-1 完整验证后交付。安装、构建、类型检查、测试和浏览器全部在 localhost-1，通过 11090 代理；本机只读改代码与 Git。

验收：现有 7 项播放器测试全部保留；新增歌单选曲、高亮与定位、LRC 解析、滚动与点击跳转、切歌竞态、空/纯文本/失败重试；视频 MP4/HLS、SSR、跨页播放、静音音量恢复与 CORS 降级不回归。真实第三方播放另行抽查，不能用夹具可用性代表所有外部链接可用。
