# VNDB、简介翻译与设备编辑

后台视觉小说编辑支持搜索 VNDB 候选条目、预览资料，确认后填入当前表单；最终保存才写库。外部资料包含关联 ID、标题、开发商、封面、发售日期、来源评分和原文。保留个人状态、评分、时长及备注；中文简介由人工确认保存，重新导入不同原文时清除旧译文并明确提示。前台展示中文简介并保留可展开原文及 VNDB 来源。

后台设置提供 OpenAI 兼容接口的 HTTPS Base URL、模型与密钥管理、启用开关和连接测试。密钥加密落库，不回显；留空保留，显式清除；切换地址需重新提供密钥。未配置时禁止翻译并提示配置。翻译生成只提供预览，不自动保存，不覆盖原文。接口仅管理员可调用，限长、限时、限制响应大小，不转发上游错误正文或密钥。测试连接会调用已保存模型。

设备支持图片上传与链接、多行规格，前台展示图片、入手日期、规格、备注和外链。无图使用紧凑卡片；旧入手日期自由文本保留。

只在 localhost-1 开发与验证，不修改 arch 生产。新增字段和配置表采用增量迁移，不自动关联旧 VN 条目。最终交付可审查分支及 PR；真实模型需用户之后在后台配置。
