# Asuna / Aincrad 首页设计

> 历史实现记录：本文中的配色、12 栏目及手机五入口不是当前锁定规范。用户已允许重做 token，确认结构、浅色视觉稿 A、A2 深色与状态，并回复“好”批准首批正式接入；首批主体已实装；旧轮 57 项检查后补出的 900px 遮挡，已由本轮正式原尺寸泊位修正并复验通过。本轮 299 单测、5 包强制类型检查及生产构建通过；扩展 66 项浏览器检查 65 过、1 红（799px 窄桌面视觉遮挡），尚未最终验收。用户随后选择保留浮动形态、先做避让预演，并再次回复“1”，批准原尺寸浮动泊位正式实现与回归：保留桌面 230×320px，只给首页下方两栏和页脚留边，使用显式工具入口及非模态互动面板。紧凑缩小版未获批准；799px 窄桌面已实测仍压文章窗，未擅自改文章窗宽度；正式接入不等于最终验收。尚未提交、合并或部署。范围与新证据见 [SAO 首页内容与结构线框](./sao-home-plan.md)。旧图形尚未迁入新首页，渲染造型问题仍按 [设定纠偏记录](./sao-reference-audit.md) 处理，不能据新首页代码声称已修。

## 方向

从《刀剑神域》艾恩葛朗特篇的界面语汇与亚丝娜的红白剑士形象提取设计元素，而不是复制官网或给原有粉色卡片换一层颜色。

- **人物性格**：坚定而温柔，冒险之外也珍惜日常。页面既有细剑和菜单的秩序，也保留照片、音乐、文字的生活感。
- **色彩**：月白 `#f6f7f9`、墨灰 `#252b35`、绯红 `#b42f3c`、香槟金 `#b69a63`、雾蓝灰 `#dce3e9`、栗棕 `#98613e`。深色改为冷调夜色，不延续全屏樱粉。
- **字体**：现有 Noto Sans 继续承担界面和正文；Asuna 字标以完整斜体衬线字形表现细剑的轻盈，不对句子中的单词随机加重或变色。
- **界面**：切角面板、菱形焦点、细边框、明确的分隔与菜单项；不放假等级、假血量、假在线指标。
- **人物**：复用仓库已有亚丝娜 Live2D 模型，离线生成透明 WebP 静帧；不是新画的角色插画。几何背景、切角边框与标题刻线由本站绘制。不下载或热链第三方同人图，不冒充官方站点。

## 结构

```text
首页
├─ 顶部身份条
├─ 人物首屏
│  ├─ Asuna / 简短欢迎 / 真实个人标识
│  ├─ 探索我的世界 / 读最近的文字
│  └─ 站内亚丝娜模型静帧 / 艾恩葛朗特的几何远景
├─ 兴趣菜单：六个重点栏目，全部栏目仍在主导航
├─ 最近沉浸的事：在听 / 在看 / 在玩
├─ 日常存档：不等宽照片编排
├─ 文字与碎念：文章列表 + 真实近况
└─ 个人说明与回到顶部
```

宽屏使用 192px 左侧分组菜单；窄屏使用五入口固定底栏与分组面板，不再横滑寻找栏目。首页使用更宽的内容画布，其他文章和内容页仍保留阅读宽度。

一级入口为首页、日常、收藏、兴趣、友链，原有 12 个栏目全部保留：

- 日常：博客、相册、说说、自慰记录。
- 收藏：音乐、番剧、影视、视觉小说。
- 兴趣：舞萌、东方、设备。
- 首页、友链直接跳转。

桌面使用原生 `details`，同一时刻展开一组，直达内容页时自动展开所属组。手机面板支持组内切换、焦点约束、Escape 关闭并回到实际触发按钮；点击栏目和切到桌面断点会关闭面板。禁用 JavaScript 时，手机显示首页与全部 12 个栏目链接，桌面仍可使用原生折叠。正文与音乐播放器的桌面避让同步调整，不改变播放状态。

## 动画边界

- Motion：导航共享高亮、菜单与内容交互；保留相册和播放器行为。
- GSAP：首屏人物与文字时间轴、远景视差、内容章节滚动线条。
- Anime.js：切角菜单边框、图标与细剑式标题签名绘制；键盘与鼠标均可触发。

同一元素不由多个库竞争 transform。减少动态效果时保持完整静态画面；无 JS 时正文、人物与链接都可用。

## 图形渲染：艾恩葛朗特远景

在既有首屏上增加远景，不改变人物、正文与内容入口的层级，也不把整个站点改成 3D 导航。

- **配色与字体**：沿用上面的月白、墨灰、绯红、香槟金、雾蓝灰和栗棕；Noto Sans 与 Asuna 衬线字标不变。绘制层直接读取现有主题 token，深色模式同步更新。
- **布局**：桌面在文字与人物之间放置浮空城，人物仍在前景；手机把浮空城移到人物左侧的下半屏，不覆盖行动入口。唯一主要视觉中心仍是 Asuna，不额外堆叠展示卡片。
- **Three.js**：程序化构建收束的浮空楼层、塔楼、绯红塔尖和轨道，不下载新人物、模型或纹理。鼠标在首屏移动时仅产生小幅视角响应，不接管滚动或触屏手势。
- **WebGPU / WebGL**：整站先过硬闸门——拿不到硬件 WebGPU adapter 的访客会被整屏拦下并要求换平台或浏览器（见下节），不为低能力设备提供替代页面。闸门放行后的渲染器仍优先用硬件 WebGPU 设备交给 `WebGPURenderer`，`WebGPU` 设备创建失败时再退 WebGL 2，上下文丢失时保留服务端 SVG 远景；这些只是运行期兜底，不再是给无 WebGPU 设备准备的降级路线。无头 SwiftShader 的软件 WebGPU 会产生原生错误域异常，因此不把它当作硬件路径的验收替代。
- **p5.js / Canvas 2D**：独立实例绘制少量菱形光尘与鼠标经过远景时的短暂细剑光线，不创建额外 WebGL 上下文。
- **SVG / CSS**：SVG 提供无脚本也完整的远景；CSS 负责远景层次、地平线、响应式和暂停开关，继续复用既有的切角菜单与刻线。

两套引擎按需、独立加载，失败不会影响正文或彼此。初始减少动态效果或省流量模式不下载引擎；运行中切换减少动态效果会销毁画布。暂停保留当前画面，首屏离开视口或标签页隐藏时停绘；离开首页时释放实例、GPU 资源、观察器和事件监听。动态上限为 30fps，限制设备像素比；不为凑技术栈增加 Wasm 或 Worker。

实现入口为 `components/public/aincrad-scene.tsx`，两层分别位于 `aincrad-renderer.ts`、`aincrad-dust.ts`，样式位于 `aincrad-scene.css`。浏览器回归为 `e2e/graphics-scene.spec.ts`。

Three.js 与 p5.js 的完整能力有包体代价：当前两块动态引擎 gzip 合计约 529 kB（生产构建量测），仅在首页允许动态效果时请求，不作为正文、导航、内容页或后台的前置条件。后续若移动端实际加载指标超预算，应先降低图形复杂度或收窄 p5 构建，而不是继续堆效果。

## WebGPU 闸门（2026-11 决定）

首屏场景、光尘和看板娘（WebGL/Live2D）都属于“能跑才有意义”的部分，因此不再做任何响应式替代或降级版首页：检测不过就整站只显示一屏拦截页。

- **判定**：`navigator.gpu` 存在，且 `requestAdapter()` 返回非软件适配器（`adapter.info.isFallbackAdapter !== true`）。只有软件适配器（SwiftShader、llvmpipe 一类）一样拦——它们能建设备，但帧率和功耗不可接受。
- **范围**：根路由统一判定，所有前台路由一起被拦；拦截页挂在 `body` 下并把其余节点 `display: none`，键盘焦点收进拦截页，被拦下的正文既看不到也 Tab 不到。
- **文案**：说明本站依赖 WebGPU，列出当前可用的浏览器/系统组合与「打开硬件加速、看 `chrome://gpu`、更新驱动」三条自助路径，提供「重新检测」按钮（装好加速后可原地复检，不必刷新）。
- **开关**：`WEBGPU_GATE=off` 关掉闸门，只给无头环境验证用——无头 Chromium 只有 SwiftShader，不关闸门所有 e2e 都会被拦在门外。
- **代价**：手机 Safari 26 以下、Firefox 141 以下、无 JS 的抓取器和部分远程桌面/虚拟机访客会看到拦截页，搜索与社交预览也拿不到正文；这是明确接受的取舍，不是待修的缺陷。

实现入口为 `lib/webgpu-gate.ts`（判定，含单元测试）、`components/public/webgpu-gate.tsx` 与 `webgpu-gate.css`（拦截页），浏览器回归为 `e2e/webgpu-gate.spec.ts`（需 `E2E_WEBGPU_GATE=on`）。

## 取舍

移除圆形花园图和重复的圆角卡片堆叠，以人物首屏成为唯一主要视觉中心。保留真正的站点数据，不为了游戏氛围伪造经历、进度或成绩。主题限定在公开前台，不替换后台的编辑界面。

## 人物静帧

输入为仓内 `@i/live2d` 管理的原有模型 `packages/live2d/assets/model/asuna/asuna_01/`，输出为 `apps/web/public/images/asuna-aincrad.webp`（821×2000，含透明通道）。不额外初始化第二套 Live2D，也不改变右下角看板娘。

在已有本地测试服务可用时重新生成：

```sh
bun scripts/render-asuna-poster.mjs http://127.0.0.1:13226 /usr/bin/chromium
```

脚本只接受回环地址，离线固定微笑表情、关闭随机动作后拍照，裁去透明留白并编码 WebP。原始角色与模型权属不因生成静帧而改变，本次没有取得新的素材许可，不应把静帧或角色宣称为本站原创。

参考：[SAO 官方艾恩葛朗特页面](https://www.swordart-onlineusa.com/aincrad/staff/)、[Bandai Namco Asuna 角色介绍](https://en.bandainamcoent.eu/sword-art-online/echoes-of-aincrad/characters/asuna)。这是非官方的视觉致意，不代表这些作品方参与了本站制作。
