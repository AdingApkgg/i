# Asuna / Aincrad 首页设计

## 方向

从《刀剑神域》艾恩葛朗特篇的界面语汇与亚丝娜的红白剑士形象提取设计元素，而不是复制官网或给原有粉色卡片换一层颜色。

- **人物性格**：坚定而温柔，冒险之外也珍惜日常。页面既有细剑和菜单的秩序，也保留照片、音乐、文字的生活感。
- **色彩**：月白 `#f6f7f9`、墨灰 `#252b35`、绯红 `#b42f3c`、香槟金 `#b69a63`、雾蓝灰 `#dce3e9`、栗棕 `#98613e`。深色改为冷调夜色，不延续全屏樱粉。
- **字体**：现有 Noto Sans 继续承担界面和正文；Asuna 字标以完整斜体衬线字形表现细剑的轻盈，不对句子中的单词随机加重或变色。
- **界面**：切角面板、菱形焦点、细边框、明确的分隔与菜单项；不放假等级、假血量、假在线指标。
- **人物**：复用仓库已有亚丝娜 Live2D 模型，离线生成透明 WebP 静帧；不是新画的角色插画。几何背景、切角边框与标题刻线由本站绘制。不下载或热链第三方同人图，不冒充官方站点。

## 结构

```text
首页
├─ 顶部身份条
├─ 人物首屏
│  ├─ Asuna / 简短欢迎 / 真实个人标识
│  ├─ 探索我的世界 / 读最近的文字
│  └─ 站内亚丝娜模型静帧 / 艾恩葛朗特的几何远景
├─ 兴趣菜单：六个重点栏目，全部栏目仍在主导航
├─ 最近沉浸的事：在听 / 在看 / 在玩
├─ 日常存档：不等宽照片编排
├─ 文字与碎念：文章列表 + 真实近况
└─ 个人说明与回到顶部
```

宽屏左侧系统菜单；窄屏保留可横滑底栏。首页使用更宽的内容画布，其他文章和内容页仍保留阅读宽度。

## 动画边界

- Motion：导航共享高亮、菜单与内容交互；保留相册和播放器行为。
- GSAP：首屏人物与文字时间轴、远景视差、内容章节滚动线条。
- Anime.js：切角菜单边框、图标与细剑式标题签名绘制；键盘与鼠标均可触发。

同一元素不由多个库竞争 transform。减少动态效果时保持完整静态画面；无 JS 时正文、人物与链接都可用。

## 取舍

移除圆形花园图和重复的圆角卡片堆叠，以人物首屏成为唯一主要视觉中心。保留真正的站点数据，不为了游戏氛围伪造经历、进度或成绩。主题限定在公开前台，不替换后台的编辑界面。

## 人物静帧

输入为仓库原有的 `apps/web/public/live2d/asuna/asuna_01/`，输出为 `apps/web/public/images/asuna-aincrad.webp`（821×2000，含透明通道）。不额外初始化第二套 Live2D，也不改变右下角看板娘。

在已有本地测试服务可用时重新生成：

```sh
bun scripts/render-asuna-poster.mjs http://127.0.0.1:13226 /usr/bin/chromium
```

脚本只接受回环地址，离线固定微笑表情、关闭随机动作后拍照，裁去透明留白并编码 WebP。原始角色与模型权属不因生成静帧而改变，本次没有取得新的素材许可，不应把静帧或角色宣称为本站原创。
